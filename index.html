How to get a contacts file

iPhone: on a computer go to iCloud.com, open Contacts, select all, then choose Export vCard. Open this app on that computer and import the file.

Mac: open Contacts, select all, then File, Export, Export vCard.

Android: tap Sync phone contacts above in Chrome.
